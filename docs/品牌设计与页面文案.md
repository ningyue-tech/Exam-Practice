# 宁跃教育 · 品牌主题与页面文案

## 本次设计
蓝色展开书本代表学习与知识积累；书脊上扬的暖橙线条与星形代表成长、跃升。标志为本次新设计的网页品牌图形，不是对既有注册商标或办学资质的证明。

标志资源：`assets/ningyue-mark.svg`（图标）、`assets/ningyue-logo.svg`（中英文横版），并提供透明底 PNG。SVG 为矢量图形，中文文字使用系统字体，不附带字体文件。网页内使用图标与真实文字组合，适配手机和电脑。

## 颜色
- 宁跃蓝：#2058D8，主按钮、强调文字和选中状态。
- 深蓝：#172F55，标题与正文重点。
- 暖橙：#EFA644，品牌跃升图形、商务营销装饰。
- 淡蓝：#EEF4FF，信息卡片与选中背景。
- 白色与浅灰：#FFFFFF / #F8FAFC，背景与阅读区域。

红色只表示检查后漏题、答错或错误信息；绿色表示全对。新考试不会因为主题色而默认标红。

## 主要页面文案
平台名称：宁跃教育 · 在线考试平台。
品牌口号：让学习更扎实，让进步看得见。
首页主文案：从一次认真作答开始，把知识变成能力。选择你的科目，开启今天的学习与检验。
学习理念：每一次练习，都是一次向上跃升。
品牌说明：围绕职业技能理论学习，提供分科练习、模拟机考与答题复盘。当前开放汽车维修、商务营销两门科目。
登录欢迎语：准备好，开启新的学习挑战。
登录提示：姓名、手机号与所选科目需同时匹配。
答题准备语：准备好，开始今天的练习。
成绩标题：宁跃教育 · 本次练习成绩。
学员支持：报名信息或名单有疑问，请联系安排本次练习的老师或管理员。

## 可维护信息
`brand.js` 可维护首页品牌文案、简介、口号、联系方式和页脚年份。电话、邮箱、地址默认留空，不会展示虚构联系信息。
`whitelist.js` 仍为两个科目的名单配置文件，不因本次主题升级改变。

## 保留的功能与边界
100分制（默认40单选×1＋20多选×2＋20判断×1）、60分钟、随机/按模块权重组卷、漏题提示、重开清红、原题答案评分、下载成绩单、原有本地进度隔离逻辑均保留。
这仍是静态练习版，不发送短信，名单可公开读取，前端校验可绕过，不自动汇总成绩；不新增或暗示真实身份认证、短信验证、云成绩、防作弊能力。
