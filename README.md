## 使用

解压后打开 `index.html`，选择科目，再点击“开始新考试”。两科均默认为：

- 单选40题 ×1分，多选20题 ×2分，判断20题 ×1分；共80题，满分100分。
- 时长60分钟，可设置1～240分钟。自定义题数必须满足满分100分，否则不开始考试。
- 单选/判断为单选框，多选为复选框，点击整行选项即可作答。
- 开始新考试时，题目序号和答题卡使用默认颜色，清除上一场考试的红色标记及漏题提示。
- 点击“查看未答”或漏答时点击“交卷评分”，才会把当前未答题号标红，并显示具体题号。填写后自动取消该题红色；已执行漏题检查的本场考试中，取消多选题全部选择会重新标红。
- 刷新只恢复本场考试的检查状态；点击“开始新考试”并成功开始后，检查状态重置。
- 手动交卷时存在未答题，会列出具体题号并阻止提交；点击题号可定位。
- 考试时间到，即使未答完也自动交卷；未答题0分。
- 交卷后显示成绩、各题答案与得分，可下载文本成绩单或打印。
- 两门科目的进度/成绩使用不同的浏览器存储键，不相互覆盖。
- 计时按截止时刻计算，关闭网页不暂停考试。

多选默认“全部选对才得分”。可在开考前选择“漏选半分、错选0分”：非空且仅选中部分正确项得1分，全对2分，有错项0分。开始后锁定本卷评分规则。

模块权重为0表示排除。模块题量不足时程序会在可用模块间重新分配；若该题型总量不足，提示调整设置，不会用重复题凑数。

### 随机答题验证

首页每科下方有“功能验证入口”，进入该页后点击“验证：随机答题并交卷”。单选/判断随机选一项，多选随机选择非空选项集，全部填完并提交。结果明确标记为随机验证，不是考生真实成绩。

普通入口：`auto-exam.html` 和 `marketing-exam.html`。
验证入口：`auto-exam.html?test=1` 和 `marketing-exam.html?test=1`。

每科的验证记录与普通作答记录也分开存放。验证入口只是方便测试的显示开关，不是权限或安全控制。

## GitHub Pages 发布

1. 在有写入权限的目标 GitHub 仓库中上传解压后的文件，让 `index.html`、`auto-exam.html`、`marketing-exam.html` 位于发布目录同一层。不要只上传ZIP，也不要只上传首页。
2. 提交到 `main` 分支（或你实际使用的分支）。
3. 仓库 `Settings → Pages → Build and deployment → Source` 选择 `Deploy from a branch`。
4. Branch选实际提交分支，Folder选 `/(root)`，点击Save。
5. 等部署成功后，在Pages设置页通过 `Visit site` 打开网站，把那个真实网址分享给学员。

通常可用公共仓库发布；账号方案与仓库设置可能影响Pages是否可用。更新已有站点时，使用本包文件替换旧版本，并保留另一科的新文件。仓库根目录已经有其他网站时，先确认目标目录，避免覆盖原站。

GitHub官方配置说明：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 数据、安全和隐私限制

这是纯前端练习/模拟机考，没有账号验证、教师后台、统一成绩数据库或防作弊能力。题库答案随HTML加载，可被查看。各学员的答案和成绩仅保存于各自浏览器，不会自动发送给教师。清除浏览器数据、使用隐私窗口或禁用存储可能导致记录丢失；浏览器之间、设备之间不自动同步。

不应将本版本用于保密、高风险、防作弊的正式考试。公开发布前确认对题库有相应使用和传播权限。原始Word文件、聊天记录和个人账号凭据未包含在发布包内。
