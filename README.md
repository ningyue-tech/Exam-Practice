# 宁跃教育 · 在线考试平台

这是在“双科目＋独立白名单＋重新开始清除标红”版上完成的**实际网页主题改造**，不是只有图片的效果稿。

> 更新现有网站前请备份。你若已修改过服务器上的 `whitelist.js`，请保留那份名单，**不要用完整包内的演示名单覆盖**。优先使用“不覆盖名单升级包”。

## 两个发布包

### 现有网站主题升级包（推荐用于你的现有仓库）
解压后，将包内文件按原路径添加/覆盖到现有仓库根目录，`assets/` 目录一并上传。本包不含 `whitelist.js`、`access.js`、`access.css`，保留现有文件即可。
这三个文件必须已经存在于同一目录，否则登录与题库入口无法使用。升级包不能脱离原网站单独使用。
不需要修改或重新录入人员名单。原来的页面文件名与访问路径保持不变。

### 完整 GitHub 网页包
包含完整页面、图标、主题、验证脚本与原有演示白名单。适合本地预览和新目录部署。
已有自定义名单时，把你自己的 `whitelist.js` 复制回来再发布。
上传解压后的文件，不是只上传 ZIP；根目录保留 `index.html`。不含任何外部CDN依赖。

## 本次改造内容
- 中文品牌“宁跃教育”、英文副标“NINGYUE EDUCATION”以及“在线考试平台”。
- 新设计书本与跃升星形Logo、宁跃蓝主色、少量暖橙点缀。
- 品牌首页、考生验证、两门考试、成绩区与考试须知统一设计。
- 顶部导航、科目入口、须知与学员支持链接可用。
- 手机端设置默认折叠，开始/交卷按钮和答题卡保留，展开后仍可设置。
- 联系电话、邮箱、地址没有真实输入，故不展示。可在 `brand.js` 补充可公开的信息。
- 不新增虚构的办学资质、校区、备案号或“官方题库”承诺。

## 功能保留
汽车维修796题、商务营销800题与原包中题干/选项/答案逐字节一致。白名单仍按auto和marketing分别维护。
默认试卷80题/100分/60分钟，三类题型、随机组卷、计时、漏题检查、重新开始清除红色、选择后消红、自动/手动交卷、成绩单下载与原有进度恢复逻辑保持。
教师随机验证入口在首页最下方“教师工具”中；仍需要对应科目名单匹配。

## 测试范围
本次69项检查在Chromium离线DOM/页面交互环境中通过；覆盖名单、跨科拦截、100分组卷、漏题、清红、全对计分、多选半分、到时交卷、随机验证、记录隔离与恢复、资源路径等。
**测试受当前浏览器导航限制，采用本地内联资源、模拟sessionStorage/localStorage；未执行GitHub Pages线上访问验收，也未验证真实浏览器存储兼容性。**
截图中的考生和成绩用于测试展示，不是真实学员记录。检验报告：`docs/宁跃教育主题_回归测试.json`。
发布后请再用真实浏览器验证：两科登录、选项作答、检查漏题、刷新恢复、重开清红、交卷与下载。

## 非安全系统的边界
本次是视觉与文案改造，**没有增加短信验证码、后台数据库或安全认证**。姓名和手机号保存在公开静态文件中，会被下载；前端校验可被绕过。不要在该文件存放敏感真实名单。
成绩保存在各自浏览器，不自动发送给老师；题库答案公开加载。不能把本版本当作保密、防作弊正式机考平台。
原题库专业内容未逐题复核；对标准、法规和争议题目须由教师复核。
