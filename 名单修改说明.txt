只改一个文件：whitelist.js

汽车科目组人员加到 auto: [ ... ] 中。
市场营销科目组人员加到 marketing: [ ... ] 中。
同一人考两科，在两个数组都加同一条姓名手机号记录。
姓名和手机号要在所选科目的同一条记录中同时匹配。

格式：
{ name: "示例姓名", phone: "13800000001", enabled: true },

enabled: false 停用，或删除整条记录。
两门题库和其他JS文件不需要因人员变动而修改。

示例：汽车测试 / 13800000001，仅汽车科目组；
营销测试 / 13800000002，仅市场营销科目组；
双科测试 / 13800000003，在两份名单中分别允许。
以上为演示字符串，不发送短信。

重要：静态文件会公开下载；此方法不保护手机号、不验证手机归属，前端校验也可绕过。
不要把真实敏感名单放进公开文件。需要真实安全登录请使用私有后端。
