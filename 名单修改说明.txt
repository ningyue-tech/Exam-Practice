宁跃教育 · 名单维护说明（v3）

一、考生验证方式
考生输入姓名和手机号后6位。尾号必须恰好为6位数字，开头为0也要保留，不输入完整手机号。

二、当前格式
whitelist.js 使用 version: 3、credential: 'name-phone-last6'。
每条记录由 salt、hash、enabled 三个字段组成，不含 name、phone 字段。
校验算法为 PBKDF2-SHA-256，迭代 600000 次；每个人在每个科目的记录使用独立随机盐。
网站用姓名和手机号后6位的规范化输入计算并比对校验值。这是单向匹配，不是可解密还原姓名、手机尾号的密文。

三、维护命令
在仓库根目录打开终端，运行以下命令之一：

node scripts/manage-whitelist.mjs add auto
node scripts/manage-whitelist.mjs add marketing
node scripts/manage-whitelist.mjs add english
node scripts/manage-whitelist.mjs disable english
node scripts/manage-whitelist.mjs enable english

add：添加记录。
disable：停用记录。
enable：恢复启用。

三个操作均可使用以下科目参数：
auto：汽车科目组。
marketing：市场营销科目组。
english：英语。

姓名和手机号后6位请按工具的交互提示输入。三个操作都严格要求6位数字，不能输入完整手机号，前导0须保留。
不要把姓名和尾号加在命令后面，不要粘贴到公开文件。工具自动更新本地 whitelist.js，检查后再提交发布。不要手工加入姓名、完整手机号或尾号字段，也不要将原始名单提交到仓库。

四、发布与已有进度
本次升级要一起发布六个 HTML 页面、access.js、whitelist.js 和更新后的英语页面脚本，不能只替换名单文件。
以后日常添加、停用或启用人员，发布工具更新后的 whitelist.js 即可。
升级会尝试迁移符合条件的旧会话和答题进度；遇到记录冲突不覆盖现有记录，不保证全部旧进度恢复。
名单停用后，对应科目访问资格失效。
新会话为 version: 2，其中 phone 字段只保存6位尾号，页面显示为5个星号加6位尾号。
新建会话和答题记录保存本人姓名、手机号后6位、验证状态和答题进度，不再写入完整手机号；旧记录迁移情况以实际校验结果为准。
普通练习与功能验证模式、不同考生及不同科目的记录分别隔离。

五、使用边界
输入只在当前浏览器校验，不发送短信，不验证号码归属，不提供服务端身份认证。
校验值随静态网页加载。随机盐及迭代计算可提高猜测成本，但不能保证无法破解，前端校验也可绕过。姓名加6位尾号不构成安全身份认证。
本次修改不清理 Git 历史，不改变仓库公开或私有状态。提交 f49b6a6 中已有的明文记录仍保留在历史中，不能因当前文件改为校验值就直接把仓库改为公开。
需要真实安全身份认证或集中管理成绩时，应使用服务端方案。
